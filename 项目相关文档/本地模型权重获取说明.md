# 本地模型与服务部署说明

本项目使用了 **Ollama** 和 **Chroma** 两个本地组件。

## 1. 部署 Ollama (本地 Embedding 模型)

Ollama 提供本地向量嵌入服务，用于 RAG 知识库的检索。

1.  **安装 Ollama**：访问 [Ollama 官网](https://ollama.com) 下载并安装。
2.  **拉取模型**：执行以下命令拉取项目所需的嵌入模型：
    
    ```bash
    ollama pull qwen3-embedding:4b
    ```
3.  **启动服务**：确保 Ollama 服务正在运行（默认端口 `11434`）。

## 2. 部署 Chroma (本地向量数据库)

Chroma 用于存储和检索 AI 知识库（RAG）数据。

1.  **环境要求**：需要 Python 环境。
2.  **安装 Chroma**：通过 pip 安装：
    ```bash
    pip install chromadb
    ```
3.  **启动服务**：执行以下命令启动 Chroma 服务：
    ```bash
    chroma run --host 0.0.0.0 --port 8000
    ```

## 3. 验证服务

在启动上述两个服务后，可通过以下链接验证其是否正常工作：

- **Ollama 验证**：访问 `http://localhost:11434/api/tags`，应能看到`qwen3-embedding:4b`。
- **Chroma 验证**：访问 `http://localhost:8000/api/v2/version`，返回版本号即为成功。
